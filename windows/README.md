# NoASR(Windows)

PC 端语音输入法(系统托盘程序):按热键说话,调用云端多模态模型流式识别,文字边识别边输入到当前光标处。功能与 `macos/` 对齐,对照清单见 [PARITY.md](PARITY.md)。

当前为采用 [MIT 协议](../LICENSE) 的早期源码预览版，从源码运行，尚未提供正式 Release 安装包。已知限制见 [预览版指南](../docs/PREVIEW_GUIDE.md)。

左下角显示 `v0.1.0 · 预览版`，完整内部版本号为 `0.1.0-preview.1`。

应用显示名称为 **NoASR**。应用、任务栏和托盘使用 `assets/noasr-windows.ico`（深灰 N、薄荷绿声波与输入光标），设置侧栏与首次引导保留双色字标和「Omni全模态语音输入法」说明，移除重复的独立图标。旧配置、历史、录音目录和自启任务标识保持兼容。

品牌字标直接使用 `assets/noasr-wordmark.svg` 的字形路径，不依赖系统或外置字体；侧栏与首次引导共用同一矢量文件。

外观保留现有 Windows 布局：浅色使用淡彩环境底光、珍珠白渐变卡片和细高光；夜色窗口与侧栏使用不透明烟灰纯色底。开关、主要按钮使用 Logo 品牌绿，焦点、选中态和录音波形使用同色系；绿底按钮配深色文字，保持对比度。

设置页默认内容尺寸为 960×680 逻辑像素；根据打开时所在屏幕的可用空间缩小，计入阴影与屏幕边距，支持 Windows 显示缩放。模型配置与首次引导不显示服务商推荐角标。

## 功能

- **附带工具 · 系统截图**:默认关闭。开关和快捷键归在同一张工具卡片内,关闭时收起快捷键,重新开启保留原设置。可添加、更改、删除多个截图快捷键,改动立即保存。默认 `Alt+Shift+A` / `Win+Shift+A`,松键后调用 Windows 自带截图工具;原 `Win+Shift+S` 保留。被占用的组合键用独立按键钩子接管。
- **识别服务**:火山方舟（推荐，默认选择，Fast 默认开启） / 百炼·北京 / 小米 MiMo / Gemini,各自保存 Key,托盘菜单一键切换服务和模型;设置里可"测试连接"(用一句合成语音实际识别一次)
- **流式回填**:模型出一点字就打一点;回填中途点鼠标、按键或切换窗口会立即停止,完整结果保留在历史;没打完时自动复制全文,按 Ctrl+V 粘贴
- **应用上下文**:附带当前程序名和窗口标题;可选附带窗口截图(默认关,只有部分模型支持,会增加首字耗时和费用)
- **热键**:单键或组合键(如 `ctrl`、`ctrl+space`);触发方式:同时支持(短按切换、长按说话)/ 长按模式 / 点按模式;Esc 取消;按着热键时按了其他键视为快捷键并取消
- **输入框长按鼠标说话**:在输入框内按住左键约 0.5 秒开始录音,松开提交;录音中点一下右键,松开后自动回车发送
- **麦克风**:跟随系统默认,插拔或切换默认麦克风自动跟上;也可手动指定
- **提示音**:铃声 / 木琴 / 气泡 / 双音 / 金币五种音色,可调音量、试听
- **录音胶囊**:位置可选跟随窗口 / 固定底部 / 跟随光标
- **历史记录**:首字耗时、总耗时、预估费用、截图占比;截图缩略图;长文折叠;播放(轻声录音自动放大)、复制、重新识别;保留条数可设(1~100 条或永久),也可关闭
- 未检测到说话声(误触)不调用模型;上传前裁剪首尾静音并压缩为 MP3(约 24kbps)
- 设置改动立即保存;首次启动(没有 API Key)显示三步引导

## 运行

首次启动默认:左 Ctrl、同时支持短按与长按、鼠标长按开启、去掉末尾标点开启、开机自启开启、气泡提示音、截图工具关闭、外观跟随系统；默认火山方舟及 Fast。自启任务需管理员权限,创建失败时提示并显示实际状态;已有配置优先。

需要先安装 Python 3.10+，建议使用自动检查采用的 Python 3.12。

```powershell
# 在仓库根目录执行
cd windows
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
pythonw main.pyw
```

开机自启通过任务计划程序实现:登录约 10 秒后以管理员权限启动,不弹确认框。设置时本程序需以管理员身份运行(右键桌面快捷方式 →"以管理员身份运行")。

## 说明

- 录音快捷键支持单键和组合键,可区分左右 Ctrl/Alt/Shift/Win。词典和系统截图使用“修饰键 + 一个普通键”,支持字母、数字、标点、功能键、方向键等系统能识别的按键;冲突会在保存前提示,Esc 用于取消录入。截图快捷键不区分左右修饰键。
- 文字用 SendInput 直接输入,不经过剪贴板;只有回填被打断时才把全文放进剪贴板。
- 若目标程序以管理员权限运行,本程序也需以管理员权限启动才能发送按键。
- Gemini 在国内需要开着 VPN(走系统代理);国内服务一律直连。
- `config.json`(含 Key)、`history.json`、`recordings/`、`app.log` 都在程序目录下,已被 `.gitignore` 忽略。出现问题时查看 `app.log`。

## 数据目录

新安装从 `windows/` 运行，配置、历史和录音保存在该目录。旧版用户应自行备份并迁移需要的数据；不要向仓库提交配置或素材。

## 数据清理

高清训练素材功能已移除，不再另开录音通道或保存训练音频、转写索引。旧配置中的 `keep_training_audio` 被忽略，下次保存配置时移除。

升级不会自动删除旧素材。确认“清空历史”或“关闭并清空”后，会一并删除旧 `recordings/training/` 中的音频和文字索引；文件被占用导致清理失败时会提示，可关闭占用程序后重试。词典、配置及其他子目录不随之删除。

存储逻辑回归检查可在项目根目录运行：`python -m unittest discover -s windows/tests`。测试仅用临时数据，不打开麦克风、不监听热键、不向其他窗口输入文字；它不代替Windows桌面实测。

本机转写 HTTP 接口已移除，不再监听本地端口。旧配置的新加坡百炼选项会回退到火山方舟，需填写该服务自己的 Key，不迁移旧节点密钥；其他已保存选项保留。
