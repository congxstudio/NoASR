# NoASR 品牌资源

- `noasr.png`：1024×1024 RGBA，珍珠白圆角底板、深灰圆润 N、薄荷绿声波及右侧输入光标；导出时清理底板外的透明碎屑。
- `noasr-windows.ico`：16、20、24、32、40、48、64、128、256 像素，供 Windows 桌面快捷方式、窗口、任务栏、托盘和构建脚本使用。整枚图标等比放大约 6.7%，圆角白色底板宽度由画布约 90% 增至约 96%，N 与底板的内部比例保持不变；Mac 图标不受影响。
- 品牌写作 `NoASR`，大小写固定；客户端短说明为「Omni全模态语音输入法」。
- `noasr-wordmark.svg`：用户确认稿描摹为路径，No 随深浅色主题变化，ASR 为品牌绿 `#00bf98`；不依赖字体或嵌入位图。
- 设置侧栏与首次引导共用字标 124×29 和短说明 11px，移除重复的独立图标，保留原侧栏宽度。应用图标继续用于任务栏、托盘和系统窗口。
- 强调色在 `ui.PALETTES` 统一维护。开关和主要按钮使用品牌绿，绿底文字用深色；链接、焦点和波形按深浅背景调整同色系明度。

macOS 使用相同图标和字标轮廓，字标导出浅色与深色 PDF，菜单栏使用 `MenuBarNoASR.png` 单色 N 与声波镂空模板图像。旧 OneMore 资源暂保留，品牌区不再引用。
