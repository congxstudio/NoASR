# OneMore 图标

- `onemore.png`：1024×1024，RGBA，透明外角，供品牌展示及后续导出。
- `onemore.ico`：16、20、24、32、40、48、64、128、256 像素，Windows 应用、任务栏、托盘与快捷方式共用。
- 品牌统一写作 `OneMore`，连写，大写 O、M；用途说明为「又一个语音输入法」。
- `onemore-wordmark.svg`：直接从用户确认的品牌稿描摹的 OneMore 字标，7 个字母均为贝塞尔路径，没有 `<text>`、字体引用或嵌入位图。设置侧栏和首次引导通过 Qt SVG 直接绘制，保留确认稿字形与字距，颜色随浅色/深色主题切换。
- 界面组合：品牌图标 56×56，SVG 字标 112×21，图文间距 6，说明文字 12px；品牌区高 68。字标可见上沿与右侧页面标题对齐，图标围绕字标和说明整组居中。菜单图标使用 30×30 显示框，保留原导航文字与布局。
- 字标来源为 1536×1024 的已确认品牌稿中英文区域（原图坐标约 x=648…1390、y=385…520）；开发对比图保存在 `design/onemore-brand-preview/wordmark-source.png`。描摹阈值 170，VTracer binary/spline、path precision 3；运行客户端不需要 VTracer。

图形为淡紫说话气泡 O、薄荷绿 M 与珊瑚色输入光标，重叠处透出淡桃色。由内置 ImageGen 从用户确认的品牌稿提取独立图标，参考 Mac 端既有薄玻璃界面与彩色图标；封装时清理底板外的透明碎屑，并生成各尺寸。浅色珍珠底板在深色背景下同样保留；不从整张 logo 截图裁切图标。

生成提示词要点：独立正视应用图标，保留已确认的 OM 字母组合；淡紫 O 左下有气泡尾角，薄荷绿 M 与 O 半透明交叠，右侧是珊瑚色竖直输入光标；珍珠白薄透圆角底板、轻盈磨砂玻璃、透明外背景；无文字、无额外物件、无展示拼图。小尺寸不得依赖文字辨认。
