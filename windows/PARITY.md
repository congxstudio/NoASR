# Windows 对齐 Mac 功能清单

以 `macos/` 为参照,记录 Windows 要搬哪些、怎么搬、做到哪一步。Mac 新增功能时在这里补一行。

状态:⬜ 未开始 · 🟡 进行中 · ✅ 完成 · ➖ 不做

2026-11-12 快捷键兼容已同步改进:Mac 名称表改为显示用途,补齐常规键并允许实际键码兜底;Windows 统一解析及跨功能冲突校验、扩展截图普通键。两端录入期间暂停相关工具快捷键并在取消/切页后恢复。Windows 逻辑及实际窗口已检查,Mac 新增自检用例待 Mac 编译执行。

2026-10-20 第 1、2 批已完成编码;5 家服务"测试连接"均实测通过;真实热键、流式回填到其他程序待用户实测。
